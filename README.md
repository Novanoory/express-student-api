#  Student Result API

A simple and clean **Student Result REST API** built using **Node.js** and **Express.js**.  
This project is created for practicing backend fundamentals like routing, handling requests, and working with in-memory data.

---

##  Features

- Get all students
- View passed students
- View failed students
- Find topper student
- Simple REST API structure
- No database (uses in-memory data)

---

## 🛠️ Tech Stack

- Node.js
- Express.js
